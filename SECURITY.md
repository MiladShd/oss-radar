# Security policy

## Supported version

OSS Radar is an actively developed portfolio project. Only the current `main` branch and the live
deployment built from it receive security fixes.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability, exposed credential, or abuse path.
Use GitHub's **Security → Report a vulnerability** flow so the repository owner can investigate it
privately.

Include:

- the affected commit, endpoint, workflow, or infrastructure resource;
- reproduction steps and expected impact;
- any logs or proof of concept with credentials removed; and
- a safe way to validate the proposed fix.

You should receive an acknowledgement within seven days. The maintainer will coordinate disclosure
after the issue is understood and a fix is available. This is a best-effort open-source response,
not a commercial SLA.
